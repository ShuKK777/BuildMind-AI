# 智筑未来 · BuildMind AI

**面向建筑全生命周期的多智能体 AI 决策引擎。**

[下载 PNG 项目卡](assets/project-card.png) · [查看矢量项目卡](assets/project-card.svg) · [进入产品预览](../README.md#experience)

## 我们想创造的，是一种连贯的工作方式。

规划者讨论一片土地的未来，建筑师回应空间的可能，工程团队面对文件与现场的约束。参与者看似处在不同阶段，却一直在为同一个项目作决定。

**BuildMind AI 希望让这些判断在同一个项目中相遇。** 让城市数据能够进入方案讨论，让设计意图能够变成可比较的建筑，让工程问题能够回到清楚的原文、依据与修改记录。

AI 组织信息、编排工具与探索可能；专业团队决定方向、作出判断。我们想让好的想法更早被看见，也让重要的决定拥有更好的依据。

## 三个入口，同一条项目路径。

| 模块 | 从一个具体问题开始 | 持续推进的方向 |
| :--- | :--- | :--- |
| **智策 / Urban Intelligence** | 这片土地，可以如何发展？ | 连接城市状态、规划意图与多智能体推演，让不同开发路径可见、可比、可反馈。 |
| **智绘 / Design Intelligence** | 这个想法，可以成为怎样的建筑？ | 连接参考理解、任务分解、生成与评估工具，让方案在比较、选择和逐步修改中收敛。 |
| **智管 / Project Intelligence** | 这份方案的依据在哪里？ | 连接施工文档、工程知识与版本记录，让审查从发现问题走向有据可依的协同。 |

规划给出方向，设计回应空间，工程带回约束。新的反馈继续进入下一轮探索。

## 产品的共同语言。

**项目语境。** 城市、地块、建筑与文档相互关联，让信息在不同角色之间延续。

**可比较的选择。** 先展开可能性，再选定方向，保留讨论和逐步修改的空间。

**可追溯的判断。** 从建议回到输入、原文、依据、工具过程和专业确认。

**持续的反馈。** 每一次选择和修改，都能成为下一次决策的起点。

## 第一个可交互窗口：北都 · 滨水新境。

0.2 工作台沿用北都原有的建筑轮廓与山水格局，把街区情景、地标设计和文档审查放在一起。比较开发阶段，在 A02 原址探索流线曲面、玻璃双塔或层叠花园，再进入施工文件中的原文与示例依据。

米制参数驱动程序化地标的实际设计几何；选定后应用回同一片街区。45 秒连续演示串联三个模块，也可以随时暂停，进入自由探索。0.1 的历史版本完整保留。

这是产品路径的交互窗口。参考图驱动生成、真实城市预测与自动文档审查，将沿着这条路径继续接入。

# BuildMind AI 0.2 · 城市共创工作台

在同一片北都场景里推敲规划、比较地标、审阅施工文档。原北都建筑的轮廓与位置作为设计起点，材料、景观、光照和工作台交互在此基础上继续生长。

## 离线启动

准备 Node.js 18.19+ 和现代 Chrome / Edge，完整解压仓库后运行：

```sh
node demo-v0.2/server.mjs
```

双击 `start.bat`（Windows），或运行 `bash demo-v0.2/start.command`（macOS）也可以。打开 `http://127.0.0.1:4173/demo-v0.2/`，保持终端打开。运行不需要联网、API key、npm install 或构建；不要直接双击 HTML。

0.1 完整保存在 `demo/` 和 `archive/demo-v0.1` 分支，通过侧栏即可返回。

## 体验路径

- **智策**：旋转、缩放、点击建筑；鸟瞰、滨水、地面三个镜头；建设前、一期、建设后；三种立面和景观表达保留相同建筑布局与体量。
- **智绘**：在 A02 原址比较流线曲面、玻璃双塔、层叠花园；修改层数、宽深参数、色调、绿化和种子，撤销或应用回街区。默认仍是原北都 A02，支持恢复原地标。
- **智管**：Word/PDF 本地预览；示例文档提供问题清单、原文定位和规则依据。上传的文件不会套用示例结论，自动审查尚未接入。
- **方案文件**：导出/导入 JSON；已应用方案在浏览器持久保存，未应用的编辑作为草稿。
- **45 秒演示**：九段叙事，支持暂停、继续、重播、退出，后台自动暂停；结束或退出恢复演示前的方案。中英切换覆盖界面及字幕。

## 原北都模型与渲染

建筑直接复用 `demo/assets/print-assembly.js` 的 27 个原始 STL 派生网格，建设后 19 栋、建设前村屋 8 栋。位置、三角形和建筑轮廓保留；按原颜色标签重新分配石材、幕墙、屋面和景观材质。地形复用原打印包的解析公式及水系，浏览器使用采样地形，不包含制造定位槽。场景外增加连续地景，隐藏打印底座与边裙，避免悬空沙盘的观感。

来源为用户提供的 `北都_15厘米_FDM地形与树脂建筑_分件打印包(1).zip`。`assets/north-source.json` 记录压缩包、各 STL 的 SHA-256 和来源尺寸。原文件不改写。最高建筑 A02：建筑件 66 mm，装配总高 72 mm；界面展示建筑件高度。

源坐标为毫米，呈现坐标按 1 mm = 1.5 场景单位转换。宽深滑杆为生成器输入尺寸，候选整体还会适配 A02 包络；高度读实际几何。不宣称真实城市测绘尺度、容积率或审批指标。景观百分比是展示配置值，体量指数是模型估算。

WebGL2 路径使用环境天空、PBR、环境反射、4096 阴影和相机缓动；CPU 兼容路径保留相同原始建筑几何和选中交互，近似纹理、雾和地面投影。CPU 不是高帧率演示的验收环境；在有显卡加速的演示电脑上验收最终材质、阴影与流畅度。

## 真实代码复用

`third_party/valdrada/` 包含固定提交的上游 MIT 源码、原始许可证和逐文件哈希。运行时实际调用 `generateBuilding`、`Batcher`、`makeKit`、`createMaterials`、`makeRng` 和信号相位函数。玻璃双塔、退台候选由上游生成；流线地标由 BuildMind 的生成器实现，使用共享材质库。

`packages/` 提供场景与状态、建筑适配、原模型地块元数据、信号与轻量人车、相机和演示时间线，可继续接入智策、智绘。没有复制完整纽约瓦片或第三方人车模型。来源及改动见 [NOTICE](../third_party/valdrada/NOTICE.md)。

这仍是交互原型：不包含任意参考图到三维的 AI 推理、真实城市交通预测或自动规范审查。

# 打印模型来源与替换约定

用户提供：`北都_15厘米_FDM地形与树脂建筑_分件打印包.zip`，以及建设前后上色效果、分件装配图和立体示意图。

- 建筑来自包内 `02_树脂建筑/` 的独立 STL，按 `source/part_manifest.json` 原坐标装配；颜色根据 `source/style_paint.json` 面域还原。网页隐藏地表以下的插接部分。
- 建设前 B01–B08，共 8 栋；建设后 A01–A19，共 19 栋。各栋保留独立 ID，可点选。
- A02「双翼地标塔」零件宽/深约 15.706 mm、高 66 mm；底标高 6 mm；中心 `(65, 74)` mm；装配最高点 72 mm，是建设后最高楼。
- 页面默认展示 A02 原始几何。只有选择智绘方案/修改方案参数后才切换为新模型；恢复原塔不重建或改动周围建筑。
- 三套新方案是为网页演示设计的程序化几何，落在同一 A02 中心。标准装配高度分别为 72 / 86 / 66 mm；低/高选项对底板上方部分应用 0.82 / 1.18 倍高度。
- 地形使用源包的高程函数与布局做低分辨率重建，非逐三角面的 FDM 底板副本。道路、鱼塘、山体和树木按原图布局重建；未保留打印孔槽与制造细节。
- 网页世界坐标：`[(sourceX-75)*1.5, sourceZ*1.5, (75-sourceY)*1.5]`；UI 始终显示源模型毫米。
- “一期开发”与情景统计是新增演示预设，不是源打印包提供的真实开发数据。

`tools/convert-print-pack.py` 只读取压缩包内的 STL/JSON，不执行包内 Python 源码。`assets/print-assembly.js` 是可重建的派生几何，原始上传包不修改、不打包进运行目录。
